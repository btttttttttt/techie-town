# 🌿 Techie Town — AI Future City

**Learn, Create, and Build the Future**

Welcome to Techie Town!

Techie Town is an educational game about technology and the future. Players can explore, learn, complete missions, and develop their own city.

## ✨ Game Features
- Explore a future city
- Complete missions
- Collect coins
- Earn scores
- Learn about technology

## 🎯 Game Goal
Learn new skills, have fun, and build your future city!
